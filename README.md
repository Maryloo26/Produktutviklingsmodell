# Produktutviklingsmodell

Denne modellen beskriver en felles, læringsdrevet tilnærming til produktutvikling med tydelige beslutningspunkter, krav til underlag og bevisste avslutningsstrategier.

## 1. Modenhetsskala med beslutningspunkter

### Faser
1. **Forstå problem**
   - Avklar problem, målgruppe og ønsket effekt.
2. **Utforske**
   - Kartlegg mulige løsningsretninger.
3. **Bekrefte**
   - Test hypoteser og reduser usikkerhet.
4. **Bygge**
   - Lever løsning iterativt med måling av effekt.
5. **Forvalte**
   - Sikre drift, forbedring og gevinstrealisering.
6. **Pensjonere**
   - Planlagt utfasing og overgang.

### Beslutningspunkt mellom hver fase
Mellom hver fase gjennomføres et fast beslutningspunkt med ett av tre utfall:
- **Fortsett** – kriterier er oppfylt.
- **Juster** – mangler/læring krever ny runde.
- **Stopp** – lav verdi, høy risiko eller for stor kostnad.

## 2. Felles produktunderlag (obligatorisk før beslutning)

Følgende skal være dokumentert før beslutning:
- Problem og behov
- Mål og verdi/gevinster
- Hypoteser og usikkerhet
- Løsningsretning(er)
- Kostnader/ressurser
- Risiko og avhengigheter

**Krav:** Hvert punkt skal inneholde refleksjon, læring og antakelser – ikke bare status.

## 3. Produktgjennomganger (før store beslutninger)

### Prinsipper
- Tverrfaglig deltakelse
- Utenfra-blikk (personer utenfor teamet)
- Fokus på læring og refleksjon, ikke rapportering

### Standard agenda
1. Hva har vi lært?
2. Hva er fortsatt usikkert?
3. Hva anbefaler vi nå: fortsett / juster / stopp?

## 4. Er vi på rett kurs, og skaper vi verdi?

### Kobling til mål og retning
- Understøtter det vi bygger målet vi skal nå?
- Har forutsetningene endret seg siden vi startet?
- Ville vi startet dette i dag, med kunnskapen vi nå har?

### Skaper vi faktisk verdi?
- Hvem opplever verdi av det vi leverer, og hvordan vet vi det?
- Stemmer de opprinnelige hypotesene om verdi, eller må vi justere?
- Er innsatsen proporsjonal med verdien vi faktisk skaper?

## 5. Tydelige exit-kriterier – tre måter å avslutte godt på

### 1) Kursendring (pivot eller innsnevring)
Vi avslutter nåværende retning bevisst og starter noe nytt basert på læring. Dette er ikke feil, men nødvendig justering.

**Tegn på at kursendring er riktig:**
- Hypoteser er avkreftet
- Behovet er annerledes enn antatt
- Bedre muligheter er synlige

### 2) Stopp (planlagt avvikling)
Produktet eller initiativet avsluttes fordi verdien ikke forsvarer videre innsats. Avviklingen gjøres ryddig med dokumentasjon og overgang.

**Tegn på at stopp er riktig:**
- Lav verdi for brukerne
- Høy vedlikeholdskostnad
- Kompetansen gir mer verdi andre steder

### 3) Pensjonering
Produktet har tjent sitt formål. Brukere flyttes til nyere løsning, eller behovet er borte. Produktet fases ut kontrollert.

**Tegn på at pensjonering er riktig:**
- Avtagende bruk
- Alternative løsninger er klare
- Teknisk gjeld overstiger nytte

Alle exit-strategier er gyldige utfall, ikke tegn på feil. En bevisst avslutning er bedre enn å videreføre noe som ikke lenger skaper verdi.
